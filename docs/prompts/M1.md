# M1 — Access core (fast track, P2-12 + P2-14)

Context: README §13.5 (enforcement, `/v1/admin/me`), §8.2 `audit_logs`, BR-13. P2-11 left a live but uncached `DbPermissionResolver` and an interim `@SuperAdminOnly` guard. Goal: make authorization production-shaped and audited so every later admin screen/API can rely on it.

## P2-12 Authorization engine
- `EffectivePermissions` gains `hasRole` and per-permission drawer `scopes` (`'all'` or a set of drawer ids). Helpers: `holds`, `drawerAccess`, `canAccessDrawer` (Super Admin = all).
- `PermissionAuthority` = caching resolver over the DB resolver: TTL cache (`PERMISSION_CACHE_TTL_SECONDS`, default 30, 0 = off, measured with the injected Clock), `invalidateUser(id)`, `invalidateAll()`, generation counter so a load that started before an invalidation is never stored. Invalidated by role edit/delete, admin role set/deactivate. Still re-reads after TTL on other instances (documented bound).
- `@RequireAdminAccess()` (any role holder) for `GET /v1/admin/me` → `{ user, superAdmin, permissions[], drawerScopes[] }` (drawerScopes only for permissions restricted to drawers).
- Route-enumeration test: every controller route under `/v1/admin` declares a permission (or admin access) and uses `PermissionGuard`; the test fails the build otherwise.

## P2-14 Lean audit log
- Migration `0007_audit_logs`: append-only (triggers reject UPDATE/DELETE for every role), indexes by entity and actor.
- `AuditService.record(trx, …)` in the caller's transaction, deep redaction of secret-looking keys, `reason` optional, `ip` from the request.
- Wired into role create/edit/delete, admin role set/deactivate, invitation create/revoke/accept, Super Admin bootstrap (actor null). Reading audit rows = P2-34 (after the demo).

## Tests
Unit (scope helpers, cache TTL/invalidation/generation, redaction), db (append-only, ordering, nullable actor), api (`/admin/me` for super admin / scoped role holder / customer; changes visible at once after invalidation; enumeration test; each mutation ⇒ exactly one audit row with actor/before/after; rollback removes the audit row). Mutations: skip guard, cache never invalidated, audit outside the transaction.

Done = `pnpm verify` green, Evidence + ticks + log.
