# M20 — real-UI testing and faster verify (P3-42, P3-43, P3-24 part)

**Goal:** every layer is tested through the real thing, and the full check takes about half the time.

**Scope**
- `pnpm test:live-ui`: real admin panel in a browser against the real API and a throw-away database (`scripts/lib/live-stack.mjs`), specs in `apps/admin/e2e-live` (L-01…L-11).
- `pnpm test:live-android`: the real Flutter app on an Android emulator against the same kind of stack; `apps/mobile/integration_test` (J-A1, J-A2).
- `pnpm verify:parallel`: lanes (static, api, admin, mobile) side by side; the concurrency suite last and alone.
- Fix whatever the real UI finds (sideways scrolling on phones).

**Rules:** no stubs in the live tests; the database is created and dropped by the script; a browser error fails the spec; no retries.

**Done when:** live admin 11/11, live Android green, `pnpm verify:parallel` 16/16, plan updated.
