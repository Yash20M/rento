# M15 — Admin polish: pagination, charts, visual refresh (fast track: P3-36, P3-37, P3-38)

Owner request (2026-10-18): "use pagination in the admin panel, charts, make it more beautiful, modern UI".

## Decisions (engineering defaults — flagged)

- **Pagination**: the API pages by opaque cursors (stable under inserts, no total count), so the panel pages with **Previous / Next**, "Showing 26–50 rows · page 3" and a **rows-per-page** choice (10 / 25 / 50, remembered per table). Going back is exact (a stack of the cursors already visited), changing a filter or the page size returns to page 1. Replaces "Load more" on Bookings, Customers, Assets, Payments and the Audit log. Numbered page links and a total count would need offset paging or a count query on every list — not worth the cost and inconsistency; revisit if staff ask.
- **Charts**: a small dependency-free SVG kit (smooth gradient area, rounded bars, donut with legend, ranked bars) instead of a chart library — nothing new to audit or keep patched, a few KB, fully themeable. Every chart has hover tooltips and an invisible data table for screen readers; text keeps its size on every screen width (the chart measures its box). Dashboard: 14-day money trend (only for people who may read reports; silent when unavailable) and a "bookings in flight" donut. Reports: money and bookings per day (every day of the range, quiet days as zero), outcome mix, ranked drawers and products; the old tables stay under "See the numbers as tables".
- **Look**: brand indigo palette with matching chart colours (light and dark, tokens only), card/table/button polish, grouped sidebar (Operations, Catalogue, Team, Insights) with icons, sticky translucent header, avatar, skeleton loaders, dark mode switch (remembered, follows the system by default), phone layout with a slide-in menu, reduced-motion respected.

## Tests

Pager (6): rows/page indicator, cursor walk both ways without skips or repeats, page-size change + memory + survives unusable storage, filter resets, no pager when empty. Charts (11): axis maths, smooth path never overshoots, tooltips, tables, empty/single data, donut shares, bar proportions. App (8): theme switch + memory, grouped menu, phone menu, no empty headings, dashboard trend with zero-filled days, silent without permission/on failure, reports charts.
