## 5. Detailed requirements
1. **Project identity**: Android `applicationId` and iOS bundle id `com.rento.app` (**placeholder** — must be confirmed before P0-02/03/04 register SHA-1s/bundle ids; flag to the user), app label "Rento", `minSdk` from Flutter default, portrait + landscape allowed.
2. **`AppEnv`** (`app/config/env.dart`): fields `flavor` (`dev|staging|prod`), `apiBaseUrl` (no trailing slash), `sentryDsn` (nullable). `AppEnv.fromDefines()` reads `FLAVOR`, `API_BASE_URL`, `SENTRY_DSN` via `String.fromEnvironment`; `AppEnv.parse({...})` is the pure, testable core. Rules: `FLAVOR` default `dev`, unknown ⇒ `EnvException`; `API_BASE_URL` default **only for dev** = `http://10.0.2.2:3000` (Android-emulator loopback to the host); staging/prod without it ⇒ `EnvException`; must be `http(s)` URL with a host; **prod must be `https`**; trailing slashes trimmed; empty `SENTRY_DSN` ⇒ null. `EnvException` message names the key, never echoes a DSN.
3. **Providers** (`app/providers.dart`): `envProvider` (throws unless overridden), `secureStoreProvider`, `dioProvider` (built from env), `routerProvider` (`GoRouter`).
4. **`SecureStore`** (`core/storage/secure_store.dart`): abstract `read/write/delete(String key)`; `FlutterSecureStore` wraps `FlutterSecureStorage`, prefixes every key with `rento.` , uses the library's default Android options (flutter_secure_storage 10 uses a Keystore-backed AES-GCM cipher; `encryptedSharedPreferences` is deprecated there) + iOS Keychain `first_unlock_this_device` accessibility; `InMemorySecureStore` for tests. Nothing here stores tokens yet (P3-11 does).
5. **Dio shell** (`core/api/api_client.dart`): `buildDio(AppEnv)` ⇒ `baseUrl` = env, connect timeout 10 s, receive timeout 20 s, send timeout 20 s, default headers `Accept: application/json`; no interceptors yet except a debug-only log interceptor that **never logs headers or bodies** (tokens). Keep dio's default `validateStatus` (non-2xx throws `DioException`) so P3-11's error mapping sees them.
6. **Router** (`app/router.dart`): `GoRouter` with `/` → `HomePage`; `errorBuilder` → a "Page not found" screen with a button to `/`. No redirects yet.
7. **Theme** (`app/theme.dart`): Material 3 `ColorScheme.fromSeed` light and dark, `ThemeMode.system`, consistent `visualDensity`.
8. **App** (`app/app.dart`): `MaterialApp.router` with theme, router, localization delegates, `supportedLocales: [en]`, `onGenerateTitle` from l10n.
9. **Home** (`features/home/presentation/home_page.dart`): app bar title from l10n, headline "Rent by the hour", body text, a flavor chip shown **only when flavor ≠ prod**.
10. **l10n skeleton**: `l10n.yaml` (`arb-dir: lib/l10n`, `template-arb-file: app_en.arb`, `output-dir: lib/l10n/generated`, `synthetic-package: false`, `nullable-getter: false`), `app_en.arb` with `appName`, `homeTitle`, `homeHeadline`, `homeBody`, `notFoundTitle`, `notFoundAction`, `envFlavorLabel(flavor)`. Generated Dart is committed.
11. **Boot failure** (`main.dart`): if `AppEnv.fromDefines()` throws, run a minimal `EnvErrorApp` showing the message (readable, no blank screen); otherwise `ProviderScope(overrides: [envProvider...], child: RentoApp())`.
12. **Quality**: `flutter analyze` reports **no issues** (including infos); `dart format --set-exit-if-changed lib test` clean; no `print`; no secrets; `analysis_options.yaml` enables `strict-casts`, `strict-inference`, `strict-raw-types` and `flutter_lints`.
13. **Docs**: `apps/mobile/README.md` — how to run each flavor (`flutter run --dart-define-from-file=config/dev.json`), emulator host address note, tests, regenerating l10n, the placeholder application id warning.
