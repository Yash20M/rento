# M16 — Android app redesign (fast track: P3-39, P3-40, P3-41)

Owner request (2026-10-18): "the UI of our Android app is very basic — use modern UI, make it more beautiful, better UX".

## Decisions (engineering defaults — flagged)

- **Design system (P3-39)**: Material 3 with the brand seed `#4F46E5` (matches the admin panel) in the *vibrant* variant, light and dark following the system; rounded 20 px cards with hairline borders, 52 px filled buttons with 16 px corners, filled text fields, stadium chips, a pill navigation bar, centred-left bold titles, soft hero gradients. Shared pieces in `core/ui/kit.dart` (`Pill`, `SectionTitle`, `Skeleton`/`CardSkeletons`, `EmptyView`, `BrandHeader`). Skeletons are **static** (no endless shimmer) so screens settle and tests never wait on an animation.
- **Explore / drawer / product (P3-40)**: greeting hero with the location bar inside it, nearby cards with distance and open-now pills, skeleton loading, pull-to-refresh; drawer page with an address/hours card (pickup instructions highlighted) and **photo-first product cards** (cover photo, price, stock pill); product page with a swipeable photo gallery + dots, a **horizontal date strip**, time chips, a price breakdown card and a **sticky reserve bar** (total + Reserve, disabled until a time and length are chosen).
- **Booking / bookings / account (P3-41)**: status pills (green completed/active, amber held, primary confirmed, grey cancelled/expired), booking cards with a date block, empty states with icons, a countdown **ring** on checkout (turns red in the last minute) and a green check on the confirmation, an account header card with avatar and grouped tiles, a brand mark on sign-in/register.
- Every existing widget key and every user-visible string used by the flows is kept, so the 148 existing tests passed unchanged through the redesign; 10 new tests cover the theme, the shared pieces in both themes, the new screens and accessibility labels.
- Cut (follow-ups): custom brand font (needs a licence/asset decision, Q-13), map pins, Lottie/hero illustrations, tablet layouts, a dark-mode screenshot review on a device.

## Verified

Real Android emulator (Pixel 7, API 35) against the running API: explore, location sheet, nearby, drawer, product (date strip + chips), bookings, account. Found and fixed: unselected time chips were nearly invisible (chip label colour), duplicate "Where are you?" on the empty explore screen.
