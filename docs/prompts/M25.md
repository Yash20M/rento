# M25 — admin self-service: "My account" with photo and password (P2-42, P3-48)

**Goal:** every administrator can look after their own account: name, phone, profile photo, password.

**Scope**
- API `POST /v1/me/password` (current + new password): wrong current ⇒ 401, weak/same new ⇒ 422 on `newPassword`, account without a password ⇒ 409 `INVALID_STATE`; on success every session is signed out and a "password changed" email goes out (never containing a password). `GET /v1/admin/me` now carries `avatarUrl`.
- Admin panel `/account` (every signed-in administrator, no extra permission): photo upload/remove (2 MB), name and phone, email with verified state, password form with confirmation; header chip shows photo and name and links there.
- CRUD check: categories (create/edit/delete), item models (+photo gallery), assets, drawers (+cover photo), roles, staff already exist; "retire" = status (inactive/retired/closed), never a hard delete, because bookings and payments must keep their history.

**Rules:** real browser test (live stack) for the photo and for the password round trip (put back afterwards); mutation checks on the password rules (current password check, sign-out of all sessions).

**Done when:** API tests green, admin component tests green, live UI green, contracts and Dart guard updated, full `pnpm verify` green, plan updated.
