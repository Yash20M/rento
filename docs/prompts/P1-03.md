## 3. Goal
`pnpm --filter api build && pnpm --filter api start` boots a Fastify/Nest server on the configured port that: refuses to start on bad config, logs JSON with a request ID per request, serves `/healthz` and `/readyz`, serves OpenAPI at `/docs` outside production, answers every failure as RFC 9457 `application/problem+json` with a stable `code`, and shuts down gracefully on SIGTERM/SIGINT.

## 4. Scope
**In scope**
- Typed, validated config (`zod`) that fails fast with an error naming bad keys but never echoing values.
- Fastify adapter with pino logger, request-ID generation/propagation (`X-Request-Id`), `traceId` in errors.
- Global exception filter (`AppError` + `HttpException` + validation + Fastify parse errors + unknown errors) and global `ValidationPipe` (whitelist, forbid unknown, all errors, 422).
- `ErrorCode` constant containing every code in README §14.2 (+ `INTERNAL_ERROR`, see 5.9).
- `/healthz`, `/readyz` (outside `/v1`), global prefix `/v1` for everything else.
- Swagger/OpenAPI at `/docs` + `/docs-json` when `NODE_ENV != production`.
- Graceful shutdown on SIGTERM/SIGINT; `readyz` returns 503 while draining.
- Test setup: Vitest with SWC (decorator metadata), scripts `test:unit`, `test:api`, `build`, `start`, `dev`.

**Out of scope**: see §2 (helmet/CORS, rate limit, Kysely pool, Testcontainers, OpenAPI export, auth, any business endpoint).

## 5. Detailed requirements
1. **Config** (`src/config/app-config.ts`): `loadConfig(env)` parses `NODE_ENV` (`development|test|production`, default `development`), `HOST` (default `127.0.0.1`), `PORT` (int 1–65535, default `3000`), `LOG_LEVEL` (`fatal|error|warn|info|debug|trace|silent`, default `info`), `DATABASE_URL` (required, `postgres://` or `postgresql://` URL). Returns a frozen object; `docsEnabled = NODE_ENV !== 'production'`. On failure throws `ConfigError` whose message lists `KEY: reason` for **every** bad key and **never contains the offending value** (DATABASE_URL carries a password).
2. **Request ID**: honour inbound `X-Request-Id` only if it matches `^[A-Za-z0-9._-]{8,128}$`; otherwise generate a UUID. Every response carries `X-Request-Id`. The same value is the pino `reqId` and the error `traceId`.
3. **Logging**: pino JSON; Fastify's request/response logging enabled; redact `req.headers.authorization`, `req.headers.cookie`, `res.headers["set-cookie"]`. Nest's own logger is routed to the same pino instance. Logger destination injectable for tests.
4. **Validation**: `ValidationPipe({ whitelist: true, forbidNonWhitelisted: true, transform: true, stopAtFirstError: false })`; failures → `AppError` 422 `VALIDATION_FAILED` with `errors: [{ field, message }]` (nested fields as `a.b`, one entry per violated constraint).
5. **Problem details** body: `{ type: "urn:rento:problem:<code-kebab>", title, status, code, detail, errors?, traceId }`, `Content-Type: application/problem+json`. Mapping: `AppError` → its own status/code; `HttpException` 401→`UNAUTHENTICATED`, 403→`FORBIDDEN`, 404→`NOT_FOUND`, 429→`RATE_LIMITED`, 503→`RETRY_LATER`, other 4xx→`VALIDATION_FAILED`, other 5xx→`INTERNAL_ERROR`; Fastify body-parse errors (`statusCode` 4xx, `code` starting `FST_`) → their status + `VALIDATION_FAILED` with detail "Malformed request (raw Fastify errors); Nest wraps body-parse errors in its own 400 whose safe message is passed through"; anything else → 500 `INTERNAL_ERROR`, `detail: "An unexpected error occurred."`, real error logged (with `reqId`) but never returned.
6. **Unknown route** → 404 problem+json `NOT_FOUND` (including under `/v1`).
7. **Health**: `GET /healthz` → 200 `{ "status": "ok" }` (no dependency checks). `GET /readyz` → 200 `{ "status": "ready", "checks": { "database": "up" } }` when `SELECT 1` succeeds within 2 s; otherwise 503 problem+json `RETRY_LATER`, `detail: "Database unavailable"` (no driver message). While shutting down, `/readyz` → 503 `RETRY_LATER` regardless of DB.
8. **Prefix**: global prefix `v1`; `healthz`, `readyz`, `docs` excluded.
9. **Error code `INTERNAL_ERROR`** (500) is added to `ErrorCode` and to README §14.2 (additive; needed because no generic 5xx code exists). Flag to the user.
10. **OpenAPI**: `@nestjs/swagger` document titled "Rento API", version constant `API_VERSION`, bearer-auth scheme `bearer` declared, Swagger UI at `/docs`, JSON at `/docs-json`; both 404 problem+json in production.
11. **Shutdown**: `registerShutdownSignals(app, proc = process, opts)` listens (once) for SIGTERM and SIGINT, marks readiness as draining, calls `app.close()` (stops listening, runs `onModuleDestroy`/`onApplicationShutdown`, ends the pg pool), then `proc.exit(0)`; on close failure logs and `proc.exit(1)`; a force-exit timer (default 10 s, `unref`'d) calls `proc.exit(1)`. Second signal while closing is ignored.
12. **Scripts** (`apps/api/package.json`): `build` (`tsc -p tsconfig.build.json` → `dist/`), `start` (`node --env-file-if-exists=../../.env dist/main.js`), `dev` (`tsc --watch` + `node --watch` via `concurrently`; Nest CLI 12 crashes on Node 22.13, so it is not used), `typecheck`, `test:unit`, `test:api`. API package becomes CommonJS (no `"type": "module"`), tsconfig overrides: `module`/`moduleResolution` `NodeNext`, `experimentalDecorators`, `emitDecoratorMetadata`, `outDir: dist`.
13. Secrets/precise coordinates never logged; `.env.example` gains `HOST`, `PORT`, `LOG_LEVEL`.
