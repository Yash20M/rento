# M28 — Rento brand redesign: orange identity, big pictures, responsive (P3-51, P3-52)

**Goal:** the owner (2026-10-25) finds the apps "way too basic". Give the customer app and the admin panel a modern, product-first look in the Rento brand: the orange of `logo.png` (`#EF8E30`) and its white-on-orange "Rento." mark. A person renting something must see the thing first — large pictures — and nothing may overlap or overflow at any screen width.

**Scope**
- **Brand assets** from `logo.png`: cropped mark, Android/iOS/web launcher icons, favicon, bundled fonts. No new Dart/npm dependency.
- **Customer app (P3-51):** new colour system (orange primary, warm neutrals, accessible ink-on-orange for buttons because white-on-`#EF8E30` is 2.6:1), logo in sign-in, header and splash, bigger covers (drawer cards, drawer page, product tiles, product/slot page, booking pages), product-first Explore, responsive layout (phone → tablet → desktop web: centred column / grid, no fixed widths), dark theme in the same palette.
- **Admin panel (P3-52):** same tokens (`index.css`), logo in sidebar, sign-in and favicon; layout checked at 360 / 768 / 1280 px.
- **Verification:** every screen of both apps opened in a real browser (headless Chrome via Playwright) at phone / tablet / desktop widths, text-overlap and overflow checked, flows exercised (sign in → find → reserve → pay → cancel; admin pages), screenshots kept in `docs/ui/m28/`.

**Out of scope:** new business behaviour, API changes, new screens that need new endpoints.

**Rules:** all existing invariants hold; accessibility tests (tap targets, contrast, axe) must stay green — contrast is fixed in the palette, never by loosening a test; existing keys/semantics labels stay so tests keep working.

**Tests:** existing suites stay green (Flutter, admin, live UI); add widget tests for the logo widget, responsive width helper (layout at 360/800/1280 without overflow) and a screenshot-driven overflow sweep.

**Done when:** `pnpm check`, `pnpm mobile:analyze|test|format:check`, `pnpm --filter admin test`, live UI tests green; screenshots reviewed; DEVELOPMENT_PLAN P3-51/P3-52 recorded with Evidence.
